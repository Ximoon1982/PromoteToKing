OAuth security/validation scope
-------------------------------
- Authorization Code + PKCE S256 and state validation retained.
- Exact configured redirect URI retained through authorization and token exchange.
- Access/ID tokens are held only in the protected PHP session and never returned to browser JavaScript.
- ID-token alg=RS256, issuer=https://oauth.chess.com, configured audience and expiration are checked.
- PubAPI gateway only accepts allowlisted https://api.chess.com/pub/... URLs and selected safe request headers.
- Batch and logout actions require same-origin session CSRF tokens.
- PHP session lock is released before outbound parallel PubAPI work.
- Independent JWT signature verification is NOT claimed by v2.9.8; no signing-key/JWKS verification mechanism is bundled. The release deliberately records this limitation rather than treating decoded claims as independently signature-verified.
