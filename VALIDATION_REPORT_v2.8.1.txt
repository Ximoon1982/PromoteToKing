Known data limitation
---------------------
The original v2.8 seed snapshot did not contain per-match lineup ratings. Historical opponent rating-bracket analytics therefore populate as authoritative match details are refreshed. Time-control and W/D/L analytics use already stored historical fields.

Production limitation
---------------------
The actual schema migration was not executed against the user's production IONOS credentials in this validation environment. Migration SQL is additive/idempotent and is invoked automatically by the deployed Team Points endpoints/CRON.
