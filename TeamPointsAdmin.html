The resumable tool supports arithmetic-only, former-member and full audits. It stores only possible issues, can pause safely, continues after individual API errors, and can repair selected issues or batches of 5, 10 or 25 before the scan is complete.

Which audit should be used?

Arithmetic audit: uses stored authoritative board counts, participations, game events and scores. It requires no Chess.com requests and quickly identifies summaries that are certainly inconsistent.

Former-member audit: verifies only finalized summaries involving a stored participant who is no longer a current club member.

Full audit: checks all finalized summaries against Chess.com. API failures are retained as review issues and do not stop the remaining scan.
