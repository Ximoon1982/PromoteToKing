# Team France Medal Engraver 0.1.0
Standalone authorized page, client-side renderer based on TCMAC 0.1.3 (01c07cfcc735aaf57424ee74312b8bafdd127bfd). Uses original uploaded PNGs, no resampling or alpha edits. The supplied artwork has slight pixel differences; preserve them exactly. See artwork.json for exact hashes and common safe polygon. Plate rectangle (225,1015,642,189); text rectangle (270,1043,553,134); flat. The safe polygon is inside all three writable surfaces. Default 30/30/20 font sizes follow TCMAC; actual glyph metrics and fit constrain output. Calibration overlay is preview-only. Leaderboard read only, no refresh requests. No new DB/cron. Approved binary assets must be supplied in assets/{gold,silver,bronze}.png; release installer contains exact originals. GitHub connector cannot transfer local binary payloads in this environment. Verify hashes before building.
