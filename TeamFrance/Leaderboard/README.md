# Team France seasonal leaderboard 0.1.0
Standalone public application /TeamFrance/Leaderboard/ with authenticated administration /TeamFrance/Leaderboard/admin/. English administration, French public widget, 260px x 590px iframe. Current season per category, five default rows, expandable pages of 25, compact player profile.

SQLite in protected data/leaderboard.sqlite3, content-addressed raw observations under data/sources. Back up the entire data directory (use SQLite online backup or stop writes for a coherent DB snapshot). Do not expose this directory publicly. Existing Team France and TGP widgets, P2K core and cron remain unchanged.

Assign Daily matches by URL/ID or club index, arenas by URL/ID, one season per event. Only completed Daily games and completed arena Results CSVs contribute. Daily wins 1, draws 0.5, losses 0, match-specific fair_play_removals applied before global account exclusion. Arena points are official Score, only Team France attributed rows. Failed or inconsistent source responses preserve previous verified results. Archived seasons remain public, excluded from routine event collection; account exclusion applies globally. Historical participants remain eligible unless closed for Fair Play. Verified stable player IDs merge aliases; unresolved identities are reported, never guessed.

Public read renders local rankings, then one bounded refresh request per display; shared lock, event status cache, one player check/minute at most and 500/day cap. Active matches 15 minutes, completed Daily 1–7 days, upcoming Daily 6 hours, arena awaiting results 30 minutes. Completed arena sources persist until explicitly refreshed. Full Refresh All uses P2K foreground adaptive OAuth bearer batch gateway for Daily and player requests; official arena CSV acquisition uses separate HTTP transport. Browser-driven jobs persist checkpoints, can pause/resume/stop, and require verified Team France admin plus CSRF. No CRON or permanent worker. Recalculate uses persisted results only.

Install via verified standalone SSH package, not P2K Release Control. PHP >=8.1, PDO SQLite and cURL in both CLI and web SAPI. After installation verify public view, admin access and that data/ URLs are inaccessible. Initial season creation and refresh are admin actions. No production credentials, data or external requests are required for CI fixtures.
