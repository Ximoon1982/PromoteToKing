# Install v2.9.22.4

Preferred production path: deploy the v2.9.22.3 → v2.9.22.4 incremental archive using `update-v2.9.22.3-to-v2.9.22.4.sh` from the production PromoteToKing root.

The updater does not require PHP CLI and performs no database migration. Protected local configuration is preserved and existing v2.9.22 CRON entries remain unchanged.
